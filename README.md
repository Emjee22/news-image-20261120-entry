A newspaper front page that sums up Friday 20 November 2026 in one picture:
28 stories across six continents — Cyclone Akvan's landfall in Odisha, the
Trump–Xi–Putin trilateral declaration, the Houthi missile over Riyadh, Europe
ready to talk to Russia, and the rest of the day, plus a DATE CHECK that keeps
19 November's news out of the frame.

`entry.png` (1024×1024) is drawn from scratch by `draw_news.py` (Python +
Pillow): every flag, illustration, map and letter is drawn in code — no
photograph, no downloaded image. `main.ts` (Node 22, standard library only)
copies it to `/output/entry.png`.

Entry for the [news-image-20261120](https://make.fun/bounty/news-image-20261120)
competition on make.fun.
